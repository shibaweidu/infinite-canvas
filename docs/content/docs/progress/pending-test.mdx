# 待测试
- 分镜 Agent 连接角色板后，运行时会读取直连角色板中的角色、场景、道具作为主体库，并在提示词中要求镜头 `references` 使用角色板主体名称；写入分镜板时会自动把 references 匹配为角色板素材，主体参考区应显示对应名称和缩略图。重试分镜 Agent 时也应保持同样读取和匹配规则。
- 画布框选多个节点后，未打组状态下也可以拖动临时选择框或四角控制点整体移动已选节点；打组后分组容器四角控制点支持自由调节组的宽高和位置，组内节点不会被缩放。
- 画布分组顶部导航在缩放画布时保持默认屏幕尺寸，不随画布一起放大或缩小；节点悬浮导航改为复用分组顶部导航的主题化胶囊样式，按钮、分隔线、hover 和选中态需要在深色/浅色画布主题下保持清晰。
- 画布左侧“短剧制作”节点弹出面板打开后，单击面板外任意区域会自动关闭；分镜板“主体”参考选择会自动读取角色板素材，优先读取已连接到当前分镜板的角色板，没有直连角色板时读取画布上全部角色板条目，支持搜索、多选，并把角色/场景/道具缩略图和名称写入当前镜头主体参考。
- 智能体面板底部模型选择框改为靠左对齐；剧本 Agent 直接连接下游文本节点时，生成结果会写入该文本节点，不再额外创建新的文本结果节点；角色板在画布可见入口、节点标题和 Agent 写入进度中统一使用新名称；角色 Agent / 分镜 Agent 直连角色板 / 分镜板时会优先写入直连目标，没有直连时才复用或创建结果板。
- 角色板下方的生图面板改为完全复用分镜板生成面板：角色选择、提示词输入、模型选择、图片参数和积分生成按钮使用同一套布局，切换角色会自动切换对应提示词并生成到对应角色卡片。
- 角色板和分镜板的图片/视频独立编辑页底部生成面板调整提示词输入框高度：默认高度变为原来的 2 倍，点击展开后可向上撑到右侧生成外框顶部附近，便于编辑长提示词。
- 画布左侧新增“短剧制作”入口，集中创建故事设定、剧本 Agent、角色 Agent、分镜 Agent、角色板和分镜板；底部工具栏移除这些短剧节点按钮，仅保留通用节点与操作。新增分镜 Agent 默认输出分镜 JSON，运行后优先写入已连接分镜板，否则在右侧创建分镜板结果节点。
- 画布和后台可见文案中的“项目设定”改为“故事设定”；故事设定节点的“故事简述”和 Agent 面板的“智能体身份设定”新增复用文本节点全屏样式和顶部编辑栏的编辑入口，长文本可在画布级全屏编辑器中编辑并实时回写；身份设定仅保留全屏编辑入口，不再显示展开/收起按钮。智能体节点顶部名称区改为“智能体身份设定”，模型选择移动到底部。
- 后台系统设置新增邮箱注册配置、邮箱验证码发送注册、Google 登录配置和对象存储配置：需要验证邮箱注册开关/邮箱必填/邮箱验证码开关对注册页和注册接口生效，SMTP 配置正确时能发送验证码，Google OAuth 回调 `/api/auth/google/callback` 能创建或绑定用户，对象存储密钥在后台读取时隐藏且留空保存会沿用旧密钥。
- 后台 Ant Design 主色和模型供应商、模型积分、故事设定管理页面的自定义强调色统一为黑色、灰色、白色；需要在深色后台下验证按钮、开关、选中态和输入聚焦态清晰一致，避免白色文字和白色背景叠在一起。

- 画布生成配置节点改为综合生成面板：节点内常驻模式切换，并在生图、文本、视频、音频模式下复用对应单独节点的输入框、`@` 素材候选、模型选择、参数入口、参考视频/文本反推占位和生成按钮；手动编辑配置节点输入框会切回普通提示词，生成时会按当前上游素材编号注入图片、文本、视频、音频引用。
- 图片节点悬浮工具栏新增“局部编辑”入口，打开后可在图片上用画笔/擦除工具绘制遮罩区域、填写局部修改要求，并通过图片编辑接口携带同尺寸 PNG mask 生成新图片节点；结果节点会放在原图右侧并自动连线，原图保持不变。
- 图片节点悬浮工具栏新增“反推提示词”入口；点击后会在原图右侧创建包含反推预设提示词的文本节点，并继续创建一个已切到“文本”模式的生成配置节点，图片节点和文本节点都会自动连到该配置节点，配置节点会预填包含原图和文本节点引用的组装提示词并自动打开，用户可自行点击配置节点开始生成。
- 图片节点悬浮工具栏新增“复制提示词”、“放大”和“超分”入口，并在末尾增加 `...` 更多按钮；点击“复制提示词”会复制生成该图片的提示词，图片没有提示词时会提示暂无可复制内容；点击 `...` 后打开 Ant Design 风格的“自定义工具栏”弹窗，可在图片节点占位上预览悬浮工具栏，信息、删除、存素材、下载、编辑和图片工具都在同一个快捷工具列表中勾选配置，并可切换是否显示按钮文字，保存后写入本地配置；`...` 配置入口固定显示，预览工具栏下方提供常驻横向滚动控制条。“放大”可在弹窗中选择 1K/2K/4K 目标像素和高清插值、双线性、最近邻算法，按原图比例生成新图片节点，已达到的目标像素会禁用并提示无需放大，最高不超过 4K；“超分”当前只打开暂未实现弹窗。
- Canvas 资源节点会按当前生成上下文显示 `图片1`、`视频1`、`音频1`、`文本1` 角标；文本节点内容框和节点底部 prompt 面板输入 `@` 时应弹出已连接资源选择器，点击缩略图或文字可插入纯文本编号，并以蓝色 token 视觉高亮。
- 文本节点连接到生成配置节点时，`@` 候选和实际生成输入应读取该生成配置节点的上游参考资源；生成配置输入统计区域应可拖动整个配置节点，预览按钮和设置控件仍保持可点击。
- 文本节点新增位于节点上方第一层的画布级悬浮编辑选项栏，通用节点工具栏会上移一层，不随节点缩放；双击编辑文本时也会显示该编辑栏，支持背景、标题/正文样式、粗体、斜体、列表、分割线、复制和展开/收起。
- 后台新增“故事设定管理”页面，可维护题材、风格分类、视觉风格名称/提示词/封面和故事预设；画布故事设定节点会读取后台配置，选中视觉风格后会把风格提示词随故事设定传给下游。
- 故事设定节点的“风格库”改为画布级大弹窗，弹出时不再被节点尺寸裁切，并按参考样式显示分类、上传卡片和风格卡片；需要验证选择或上传风格后能正确回填到故事设定节点。
- 画布新增“故事设定”结构化输入节点：底部工具栏和连线创建菜单可新建；节点内支持填写主题、选择题材、打开风格库弹窗选择或上传视觉风格、添加关键元素标签、选择或自定义时长，并在“故事简述（支持小说改编）”输入框旁选择预设故事描述；作为上游连接到 Agent 或生成节点时会传递格式化的故事设定文本。
- 画布新增“角色板”和“分镜板”两类结构化节点：底部工具栏和连线创建菜单可新建；角色板按“角色 / 场景 / 道具”分组展示资产卡，支持添加、编辑名称/描述、上传缩略图和重置；分镜板支持添加分镜、编辑描述、添加主体参考，并按“镜头编号 / 分镜描述 / 主体参考 / 分镜图提示词 / 分镜占位 / 视频提示词 / 视频占位”横向展示；点击图片/视频占位的生图或视频按钮会在分镜板外侧展开复用的图片/视频生成组件，镜头选择下拉框会自动切到当前镜头，生成成功后回填对应占位，并在分镜板右侧创建或更新“分镜组 / 镜头 X”“视频组 / 镜头 X”结果节点。
- 画布新增第一期打组功能：框选或多选两个以上节点后可通过底部工具栏或 `Ctrl / Cmd + G` 创建分组；分组以标题栏和虚线框包裹组内节点，支持拖动标题栏整体移动、双击或铅笔按钮重命名、点击解除分组；删除组只移除分组关系不删除节点；分镜板生成的图片和视频结果会自动加入“分镜组”和“视频组”。
- 画布基础手势调整为左键拖动画布空白区域直接框选节点，按住空格再左键拖动才平移画布；快捷键帮助弹窗同步更新为新的交互说明。
- 画布默认鼠标改为普通箭头，移到节点时显示可拖动手型，拖动节点时显示抓取手型。
- 画布打组交互按参考效果优化：多选未成组时显示临时选择框和顶部快捷栏，支持排列、保存到资产、创建副本和打组；成组后显示带半透明底色、四角控制点和顶部工具栏的分组容器，支持设置分组颜色、宫格/水平/垂直排列、整组执行、解组和批量下载，且不包含额外工具箱入口。
- 画布分组容器支持直接拖动移动，默认命名按“分组1、分组2”递增并跳过已有名称；未选中状态下仍保留分组背景色和对应边框以便区分；颜色和排列面板会向工具栏上方展开；组内节点拖到组外后会脱离该组，外部节点拖入组容器后会加入该组，判断依据为节点中心点是否落入分组容器。
- 画布图片节点的生成面板会显示上游已连接图片缩略图，样式与视频节点参考图缩略图保持一致；角色板下方的生图面板高度收紧，减少输入框下方空白；分组拖动补充 pointer move 路径并在分组背景区域显示移动光标。
- 文本节点、角色板和分镜板支持从节点内部右上角打开全屏查看/编辑；文本节点标题会为“展开/收起”和全屏按钮预留右侧空间，全屏后居中展示并在顶部显示编辑栏，关闭按钮使用圆形 X 图标；角色板全屏时保持原卡片排版，角色图占位放大为约 2 倍；分镜板全屏时图片和视频占位放大为约 3 倍，描述和提示词文本列会自适应填满横向屏幕宽度；角色板图片、分镜板图片和分镜板视频可进入独立全屏媒体编辑器，左侧展示历史缩略图，中间预览当前图片/视频，右侧上方编辑角色或分镜描述，右侧下方复用图片/视频生成面板，生成成功后回填当前项并追加到历史列表。
- 角色板和分镜板内容区支持在画布节点内直接用鼠标滚轮滚动，不再被画布缩放滚轮拦截。
- 角色板卡片按钮改为“生成 / 上传 / 编辑”：点击生成会在角色板下方打开复用图片节点的生图面板，支持在面板里选择要生成的角色并自动切换对应提示词；点击编辑进入该角色图片的全屏媒体编辑页。分镜板图片和视频占位按钮改为“生图/视频 / 上传 / 编辑”，编辑会进入对应分镜图片或视频的全屏媒体编辑页。
- 画布所有节点顶部新增节点名称，默认空白/旧默认名会按类型自动补为“图片节点1”“视频节点1”等编号；双击节点名称可重命名，回车或失焦保存，Esc 取消。
- 文本节点空态新增“自己编写内容 / 图片提示词反推 / 视频提示词反推”三入口；点击文本节点默认打开下方输入框，点击图片或视频反推会自动创建上游空图片/视频节点并连到文本节点，生成时文本节点会流式展示内容并支持展开文本框。
- 前端模型选择器支持再次点击选择框收回弹窗，并会按入口或节点类型过滤模型：图片入口仅显示图片模型，文本/智能体入口仅显示文本模型，视频入口仅显示视频模型，音频入口仅显示音频模型；模型弹窗改为页面级浮层，复用画布节点自身主题和圆角卡片样式，避免在配置节点里被裁切或错位。
- 后台新增“模型供应商”和“模型积分”模块：供应商页负责渠道、模型分类、模型选择和启用；积分页集中配置文本按次、图片按 1K/2K/4K 分辨率、视频按秒计费。
- 模型供应商获取到的新模型默认不选择、不启用；只有已选择且已启用模型会同步到前台公开模型列表和模型选择弹窗。
- 模型卡片编辑弹窗可维护模型类型、模型 ID、缩略图、展示名称、供应商、展示供应商名称、描述、标签、积分和 API 路由选项；需要验证与不同供应商同名模型的展示区分。
- 画布新增智能体节点和剧本 Agent 节点，可从底部工具栏或连线创建菜单新建；普通智能体保持空白智能体身份设定和自由输出，剧本 Agent 预填支持原创剧本和小说改编的标准剧本身份设定，默认 Markdown 输出；两类 Agent 面板均支持名称、智能体身份设定、模型、任务输入、上游文本/图片/视频/音频统计和输出格式，并会读取上游文本和图片调用多模态问答接口；主生成按钮在有身份设定、任务或上游输入时可运行，生成完成后会在右侧自动创建或更新文本结果节点并连接当前 Agent，重试 Agent 时也应同步更新该结果节点；Agent 节点自身内容区只展示子任务、进度和输出目标，不再承载最终结果正文。
- 画布新增“角色Agent”节点，可从底部工具栏或连线创建菜单新建；角色Agent 预填角色/场景/道具设定指令并默认 JSON 输出，生成完成后会优先写入已连接的角色板，没有连接时会在右侧自动创建角色板并连线，内容按“角色 / 场景 / 道具”三组回填名称、描述和生图提示词。
- 图像设置移除“质量”选项，新增独立“分辨率”选项，仅提供 1K、2K、4K；视频设置新增 1080p，尺寸仅保留横屏和竖屏，秒数滑块范围为 1 秒到 15 秒。
- 配置弹窗改为“配置与用户偏好”并放大为可滚动弹窗；本地直连支持配置生图、视频、文本、音频四类可选模型列表和默认模型，新建画布生图和配置节点会读取“画布默认生图张数”，需要验证远程渠道和本地直连模型列表都能正确显示。
- 画布音频节点底部生成面板改为音频提示词、音频模型下拉和 OpenAI Speech 参数设置，支持 `voice`、`response_format`、`speed`、`instructions` 并通过 `/audio/speech` 生成音频节点；需要验证本地直连和云端渠道的生成、重试、下载和刷新恢复。
- 画布左上角菜单和右上角状态栏新增“文档”入口，会使用 `NEXT_PUBLIC_DOC_URL` 配置的地址并在新标签打开文档站；需要验证登录和未登录状态下顶部入口都可见。
- 文档站搜索改为中英文混合 tokenizer，中文正文、标题和短语会按中文词、单字、二元和三元片段建立索引；需要验证 `/api/search` 和搜索弹窗能命中文档中的中文关键词。
- 文档站改为 Next.js standalone server 输出，新增 `docs/Dockerfile`、`docs/docker-compose.yml` 和 `docs/docker-compose.local.yml` 独立运行入口；需要验证文档页、搜索接口和 LLM 文本接口在文档站容器中可访问。
- 画布连线支持右键打开删除菜单；拖拽连线到目标卡片内部、连接点附近或卡片边缘外扩范围内会自动吸附并连接，拖到已有但不可连接的节点附近不会再误弹创建节点菜单。
- 外部软件可通过 URL 查询参数 `baseUrl`/`baseurl` 和 `apiKey`/`apikey` 跳转到前端；读取后会从地址栏移除这些参数，后台允许自定义渠道时会自动切到自定义渠道、填入配置并打开配置弹窗，未允许时会打开配置弹窗并提示无法导入。
- 生图工作台和画布生图会把参考图按当前顺序显示为 `图片1`、`图片2` 等编号，并在图生图请求的实际提示词中注入编号说明；需要验证 `/image` 参考图排序、画布配置节点输入顺序和画布助手参考图编号一致。
- GPT Image 生图请求会在前端把 `9:16`、`16:9` 等比例转换成合法 `WIDTHxHEIGHT` 尺寸，并在非法尺寸时直接显示中文错误，避免上游返回 `invalid_value Invalid size`。
