# 待测试
- 前台风格库新增“我的风格”：登录用户可上传风格图片到对象存储，默认命名为“风格1、风格2”，保存前可编辑名称和描述，已保存风格可再次编辑或删除；创作工作台、用户偏好默认风格、画布节点风格选择和图片/视频生成都会合并后台风格与我的风格，需要验证上传、保存、编辑、删除、选择后传递参考图和提示词都正常。
- 后台“运维管理”升级为可视化监控驾驶舱：新增 `/api/admin/ops/dashboard` 聚合接口和请求监控中间件，页面展示健康状态条、服务器资源环形图、请求趋势、状态码分布、慢接口排行、最近请求、任务队列可视化、业务健康、支付状态和模型渠道健康，需要验证 5 秒自动刷新、请求统计、慢接口排行、支付/业务数据、模型渠道状态和原有数据库备份/任务队列/日志页签都正常。
- 前台个人中心新增“我的任务”：登录用户可查看自己提交的图片生成、图片编辑、视频生成等异步任务状态，列表展示提交时间、类型、模型、状态、进度、积分、摘要和结果链接；排队中/运行中的任务会自动轮询刷新，需要验证只显示当前用户任务、不暴露模型端点或原始请求参数、生成完成后能打开结果。
- 前台“我的任务”第二版新增任务详情、图片/视频结果预览、失败/已取消任务重试和排队中任务取消；用户只能查看和操作自己的任务，详情抽屉展示任务状态、耗时、积分、结果预览和执行时间线，需要验证重试会新建 pending 任务、取消后 worker 不再执行、详情不会暴露模型端点或原始请求参数。
- 后台新增独立“任务日志”页面：支持按提交时间、任务 ID/用户/错误关键词、任务类型和任务状态筛选，展示任务总数、今日提交、排队中、运行中、失败任务和平均耗时；列表包含提交时间、结束时间、花费时间、平台、类型、任务 ID、状态、进度和详情，详情抽屉会展示任务基础信息、耗时、摘要、错误、脱敏后的请求参数和结果，需要验证图片生成、图片编辑、视频生成和数据库备份任务都能正常查询、自动刷新和查看详情。
- 任务日志第二版新增失败/已取消任务重试、排队中任务取消和详情链路入口：重试会新建一条 pending 任务并保留原失败记录，取消仅允许 pending 任务并写入已取消状态；详情抽屉可跳转用户管理和积分日志，需要验证重试后新任务进入队列、取消后 worker 不再执行该任务、列表和统计自动刷新。
- 任务日志第三版新增链路追踪：详情抽屉展示任务时间线、上游任务 ID、重试来源/重试任务、关联积分流水和结果链接；新的 AI 任务积分消费/返还流水会写入任务 ID，视频任务成功结果会记录上游任务 ID，需要验证图片/视频生成任务的积分流水、失败返还、重试关系和结果链接能正确串联。

- 后台“运维管理”新增动态仪表盘和服务器当前状态：可查看运行时长、服务器时间、操作系统、CPU 核心、Go 版本、Goroutine、GC、内存、数据目录、数据库连接池和任务队列统计；生产部署方案固定推荐 PostgreSQL，并新增 `DATABASE_MAX_OPEN_CONNS`、`DATABASE_MAX_IDLE_CONNS`、`DATABASE_CONN_MAX_LIFETIME_MINUTES` 连接池配置，需要验证接口 `/api/admin/server/status`、5 秒自动刷新和生产环境变量生效。

- 后台“提示词管理”新增自定义分组管理、自定义标签输入和导入能力：可新增/编辑/删除自定义分组，远程分组不可编辑删除；新增或编辑提示词时可选择已有标签或直接输入新标签，可从链接解析导入，也可从后台“首页内容”的作品列表按状态/关键词导入标题、封面、提示词、分类和标签，需要验证自定义分组持久化、含提示词分组删除拦截、链接导入、作品导入回填和保存流程正常。

- 后台“首页内容”将作品列表从“作品发布”中拆出为独立“作品列表”标签页，并放在“标签”之后；“作品发布”只保留生成后发布入口，首页前台作品区保持原来的分类筛选和作品网格展示，需要验证后台生成、手动新增、发布/下架、编辑/删除和前台展示流程正常。

- 后台新增“运维管理”页，包含数据库状态、SQLite 数据库备份、后台操作日志、系统任务记录和错误监控；非 GET 后台请求会写入操作日志，接口失败和 panic 会写入错误日志，创建数据库备份会先写入 pending 任务，后端异步 worker 执行成功后生成 `data/backups` 下的备份文件；需要验证后台入口、列表刷新、备份创建、错误记录和生产数据库提示是否正常。

- 异步任务队列支持用户维度和全站维度并发控制：后台系统设置可分别配置默认任务、图片任务和视频任务的单用户并发、全站并发，以及图片/视频轮询间隔；默认并发仅用于数据库备份等未单独分类任务，图片生成/编辑和视频生成按各自并发独立限流，用户编辑页的单独任务并发数仍用于默认任务兜底，`0` 表示使用系统默认；worker 会批量领取 pending 任务，并跳过已达到对应类型单用户或全站并发上限的任务，需验证备份、图片和视频任务互不挤占、全站上限和视频轮询间隔生效、running 状态刷新正常。

- 提示词远程同步成功后会为远程提示词写入创建时间和更新时间，后台提示词列表与远程同步弹窗新增更新时间显示；远程解析结果为空时不再覆盖本地旧数据，需要验证三个保留分组手动同步后数量正常且更新时间按 `YYYY-MM-DD HH:mm:ss` 显示。

- 提示词中心移除 `davidwu-gpt-image2-prompts` 和 `awesome-gpt4o-image-prompts` 两个远程采集分组，并清理本地数据库中对应提示词记录；需要验证前台分类栏、标签筛选和“全部”列表不再显示这两个分组及其旧标签。

- 后台“首页内容”的作品发布弹窗保留手动新增表单，并新增“作品链接导入”：粘贴图片/视频或普通网页链接后，后端会抓取页面媒体、上传对象存储，并调用选中的文本模型整理标题、作品信息、提示词、分类和标签后回填表单；解析模型默认复用系统默认文本模型，也可在导入区临时切换，需要验证对象存储、文本模型配置和手动保存流程正常。

- 提示词中心移除已失效的 `gpt-image-2-prompts` 远程分组，并清理本地数据库中该分组的旧提示词记录；需要验证前台分类栏和“全部”列表不再显示该分组的空白卡片。

- 后台“首页内容”、“站点管理”和“系统设置”的站点信息里新增“首页作品展示”开关；关闭后前台首页不再请求作品列表，并且不显示分类、空状态或任何作品卡片，仅保留顶部展示内容。

- 后台“站点管理”和“系统设置”的站点信息补齐“网站标题”和“网站描述”：保存后公开配置会返回 `site.title` 和 `site.description`，前台加载配置后应同步浏览器标题与 `description` 元信息；标题为空时默认跟随网站名称。

- 后台新增“支付设置”页，支持保存易支付开关、网关、商户 ID、密钥、默认支付方式和回调地址；前台个人中心点击订阅套餐或积分充值后会创建支付订单并跳转易支付收银台，支付回调成功后应只到账一次，订阅订单发放会过期积分，充值订单发放永久积分和赠送积分。
- 前台“配置与用户偏好”新增默认风格选择；用户保存后创作工作台默认带入该风格，画布中新建图片、视频和配置节点会自动带上默认风格，节点/工作台仍可手动清除风格。后台图像模型编辑新增 1K、2K、4K 分辨率启用开关，关闭后前台图像设置不再显示对应分辨率，并且扣费规则不使用已关闭分辨率的细分积分。
- 首页改为后台发布内容驱动：后台“首页内容”可维护首页文案、作品、分类和标签；后台生成图片/视频后会进入待发布作品表单，发布后才展示到首页作品库；作品详情页应展示大图/视频、作品信息、提示词和“做同款”，点击做同款会跳转创作工作台并回填模式、提示词和模型。
- 画布空白处双击或右键可弹出新增节点菜单；菜单滚动区域阻止画布缩放事件吞掉滚轮，需验证长列表可正常滚动，且从空白菜单创建节点时不创建连线、从连线菜单创建节点时仍自动连线。

- 前台顶部导航调整为品牌区、网站名称、广告语和“我的素材”前的主要导航靠左展示，“公告”及其后的入口和用户操作靠右展示；顶部与画布菜单中的“文档”入口已移除；前台导航和后台管理侧边栏品牌图标统一读取站点上传 LOGO。

- 后台“套餐与积分”新增前台展示配置：订阅套餐可配置前台原价、价格周期、按钮文案、积分模块文案、积分换算说明和权益列表；积分充值改为独立充值面板，后台充值包可配置充值金额、获得积分和折扣额外赠送，需验证新增、编辑、保存后前台显示与后台配置一致。
